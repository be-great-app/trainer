# Трекер тренувань — інструкція запуску

Додаток складається з двох частин:
- **Google Таблиця + Apps Script** (Code.gs) — тут живуть програма тренера і твій журнал;
- **веб-додаток** (index.html, manifest.json, sw.js, іконки) — відкривається на телефоні, працює офлайн.

Спершу можна просто спробувати: відкрий index.html → «Спробувати демо». Там уже є програма тижня 1, записи зберігаються лише на пристрої.

## 1. Google Таблиця (5 хв)

1. Створи нову таблицю на drive.google.com, назви «Тренування — Аліна».
2. Розширення → Apps Script. Видали вміст Code.gs і встав туди вміст файлу `Code.gs`. Збережи.
3. Вгорі обери функцію `setup` → «Виконати». Дозволь доступ (Google попередить «неперевірений застосунок» → Додатково → Перейти). З'являться аркуші **Програма, Журнал, Сесії, Налаштування**.
4. В аркуші **Програма** встав дані тижня 1 (CSV з документа: Файл → Імпорт → Вставити → «Замінити поточний аркуш» не обирати, а «Додати до поточного аркуша»; або просто скопіюй рядки під заголовок).
5. В аркуші **Налаштування** лежать два токени: `WRITE_TOKEN` (для тебе) і `READ_TOKEN` (для тренера).

## 2. Опублікувати бекенд (2 хв)

1. В Apps Script: «Розгорнути» → «Нове розгортання» → тип «Веб-застосунок».
2. Виконувати від імені: **Я**. Хто має доступ: **Усі**.
3. «Розгорнути» → скопіюй **URL веб-застосунку** (закінчується на `/exec`).

Після змін у Code.gs: «Розгорнути» → «Керувати розгортаннями» → олівець → Версія «Нова» — так URL не зміниться.

## 3. Опублікувати додаток на GitHub Pages (10 хв)

1. Зареєструйся на github.com.
2. New repository → назва, наприклад `trener` → Public → Create.
3. «uploading an existing file» → перетягни **index.html, manifest.json, sw.js, icon-192.png, icon-512.png** → Commit.
4. Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через 1–2 хв з'явиться адреса `https://<логін>.github.io/trener/`.

(Code.gs і README на GitHub класти не обов'язково.)

## 4. Встановити на телефон

1. Відкрий адресу з кроку 3 на телефоні.
2. Налаштування → встав URL з кроку 2 і `WRITE_TOKEN` → «Зберегти і завантажити програму».
3. iPhone (Safari): Поділитися → «На екран Додому». Android (Chrome): ⋮ → «Встановити застосунок».

## 5. Доступ тренеру

- У додатку: Налаштування → «Посилання для тренера» → Копіювати → надішли тренеру. Він бачить програму, підходи, RIR і звіти, але нічого не змінює.
- Щоб тренер сам писав програму: поділись таблицею (кнопка «Поділитися») з правами «Редактор». Новий тиждень = нові рядки в аркуші «Програма» з `week = 2`.

## Як користуватись у залі

1. Програма → тренування → вправа.
2. Вага і повтори вже підставлені з плану; підправ −/+ за потреби.
3. Обери **RIR** (скільки повторів лишилось у запасі) → ✓. Стартує таймер відпочинку.
4. Розминкові підходи (Р1, Р2…) підставлені з колонки «Розминка», RIR для них не обов'язковий.
5. Відео: зніми підхід, який просить тренер, завантаж у Google Drive або Telegram, встав посилання в поле під вправою.
6. Наприкінці: «Завершити тренування» → самопочуття, коментар → «Поділитися» → Telegram/Viber.

Без інтернету все зберігається на телефоні й синхронізується, щойно з'явиться мережа (статус угорі праворуч).

## Формат аркуша «Програма»

| Колонка | Що писати |
| --- | --- |
| week | номер тижня: 1, 2, … |
| date | дата тренування, 02.11.2026 |
| day_no | номер тренування в тижні: 1, 2, 3 |
| order | порядок вправи: 1, 2, … (унікальний у межах дня) |
| superset | однакова літера (A, B) для вправ суперсету, інакше порожньо |
| exercise | назва вправи (однакова назва = спільний графік прогресу) |
| video | Останній / Перший і Останній / порожньо |
| warmup | `30x10, 40x8` (вага × повтори) |
| weight_kg | робоча вага; порожньо = власна вага |
| reps, sets | повтори і підходи |
| rest | `2-3 хв`, `90 сек` (таймер бере нижню межу) |
| notes | техніка і рекомендації |

Дробову вагу в таблиці з українською локаллю пиши через кому (`2,5`), інакше Таблиця може прочитати її як дату.

## Якщо щось не працює

- **«Невірний токен»** — перевір, що скопіювала токен повністю, без пробілів.
- **Статус «помилка»** — найчастіше розгортання не має доступу «Усі» або URL не закінчується на `/exec`.
- **Не бачиш нового тижня** — Налаштування → «Оновити програму з таблиці».
- **Додаток не оновився після заміни файлів на GitHub** — закрий і відкрий його двічі (перший раз завантажується нова версія).
